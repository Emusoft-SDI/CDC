# NATCODEV Stakeholder + Inner Page Prototype Pack
Generated: 2026-05-31

This pack extends the earlier dashboard/public-page prototypes into the missing inner pages and stakeholder journeys.

What is inside:
- 01-directional-prototypes: the earlier dashboard, workspace, and public-page direction screens.
- 02-inner-page-flow-boards: new prototype boards for inner pages, flow outcomes, verification, certificates, academy, marketplace, farm operations, wallet, reports, support, governance, and coordination.
- 00-docs: implementation map, stakeholder flow map, must-have inventory, and action-to-outcome matrix.

Design commitments:
- Breathable pages: summaries first, details only when opened.
- Dwarf coconut trees/seedlings where coconut imagery is used.
- No hanging features: each button/action must end in a visible state, record, report, payment, certificate, ticket, or audit log.
- RBAC remains intact. One user may hold multiple roles.
- Major modules should have their own workspace instead of one oversized sidebar.

Recommended implementation rule:
Build one shared UI foundation first, then migrate one module at a time. Do not rebuild every page at once.
