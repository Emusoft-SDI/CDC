# Action to Outcome Matrix

Public registration -> submitted application with reference/status page.
Grower document upload -> document record with pending/approved/rejected state.
Field verification assignment -> agent task with due date and checklist.
Field evidence submit -> evidence record and verification recommendation.
Approve grower -> verified status and certificate eligibility.
Issue grower certificate -> online certificate, QR/reference verification, audit log.
Revoke grower certificate -> revoked public verification state and audit log.
Enroll free course -> enrollment record and course appears in My Learning.
Pay for course -> wallet/direct transaction, receipt, enrollment unlocked.
Attempt duplicate paid enrollment -> blocked with existing enrollment/payment link.
Open course -> lesson/material delivery page.
Complete lesson -> progress update.
Submit quiz/exam -> result, pass/fail, next action.
Complete certificate course -> certificate issued and view/download/verify available.
Request academy refund before completion -> refund ticket/workflow.
Request refund after completion/certificate -> blocked or rejected with reason.
Add farm hand -> worker profile and farm assignment.
Submit farm activity -> activity log, evidence, farm report update.
Log intercrop/livestock record -> performance dashboard and report update.
Add product/service -> draft listing.
Submit listing -> approval/inspection state.
Approve listing -> public marketplace/storefront visibility.
Place marketplace order -> payment, order record, stock reservation/deduction.
Fulfill order -> buyer order timeline and seller settlement state.
Open dispute/refund -> support case and linked transaction/order.
Fund wallet -> transaction ledger and balance update.
Withdraw/payout -> payout request, approval, settlement history.
Export report -> generated file and export audit log.
Import CSV -> validation preview, success/error rows, import log.
Submit support ticket -> ticket number, assignment/routing, status timeline.
Resolve support ticket -> resolution note, close state, feedback request.
Assign role -> menu/actions update based on RBAC and scope.
Enable module -> module available to permitted roles.
Disable module -> hidden/locked module state and audit log.
Set state coordinator scope -> coordinator sees assigned state only.
Select state in report -> LGA dropdown loads for that state.
Create certificate type -> future issuance option with validity/fee/rules.
Create certificate pathway -> grouped certificate eligibility based on course completion.
