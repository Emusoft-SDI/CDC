# NATCODEV Full Stakeholder Flow Map

## Public Visitor
Entry points:
- Homepage
- Public marketplace
- Public academy catalog
- Certificate verification
- Grower registration
- Provider/seller registration
- Support/contact

Must-have flows:
- Browse marketplace -> open product/storefront -> login/register or contact/buy -> order/request outcome.
- Browse academy -> open course -> login/register -> enroll/pay if required -> course appears in My Learning.
- Verify certificate -> enter reference or scan QR -> public verification result with status.
- Start registration -> submit form -> receive reference/status page -> dashboard activation after approval.

## Grower
Menus/workspaces:
- Overview
- Wallet
- Academy
- Marketplace
- Seller Central if approved
- Farm Operations
- Reports
- Healthcare
- Account Upgrade
- Profile
- Verification
- Certificates
- Support Desk
- Admin Console if role allows

Must-have inner pages:
- Profile and farm profile
- Identity and farm verification
- Document upload and status timeline
- Grower certificates library
- Academy My Learning
- Course detail/materials/lesson/quiz/certificates
- Farm operations: coconut, intercrops, livestock, farm hands, activities, advisories
- Wallet funding, transaction history, refunds
- Marketplace orders and buyer activity
- Support ticket detail
- Reports and exports

Critical grower flows:
- Register -> complete profile -> upload documents -> field verification -> approval/rejection -> certificate issued.
- Register for free course -> course appears under Academy > My Learning -> complete lessons/quiz -> certificate if eligible.
- Register for paid course -> wallet/direct payment -> transaction recorded -> course unlocked -> no duplicate paid registration.
- Download certificate -> view certificate online -> public QR/reference verification.
- Farm operations -> log activity -> generate advisory/report/outcome.

## Farm Hand
Must-have inner pages:
- Profile
- Assigned grower/farm
- Employment type: full-time, part-time, consultant, seasonal
- Activity categories and task list
- Attendance/evidence submission
- Safety training
- Work history and reports
- Support

Flow:
- Grower/admin adds farm hand or farm hand registers -> assigned to farm -> receives tasks -> submits evidence -> grower/agent reviews -> activity report updated.

## Input Provider
Must-have inner pages:
- Business profile
- Coverage states and LGAs
- Accreditation documents
- Product catalog
- Inventory
- Product approval status
- Orders
- Wallet/settlement
- Academy accreditation
- Provider certificate
- Reports/support

Flow:
- Register -> submit documents -> accreditation review -> approved -> products listed -> orders received -> fulfillment -> settlement -> reports.

## Service Provider
Must-have inner pages:
- Business/service profile
- Coverage manager
- Services catalog
- Availability and booking/request settings
- Accreditation documents
- Service request details
- Wallet/settlement
- Academy training/certificates
- Reports/support

Flow:
- Register -> accreditation -> publish service -> receive request -> accept/complete -> payment/settlement -> rating/report.

## Marketplace Seller
Must-have inner pages:
- Seller dashboard
- Storefront profile
- Product listing
- Add/edit product
- Inventory
- Orders
- Fulfillment
- Disputes/refunds
- Payouts
- Reviews
- Reports

Flow:
- Approved seller -> configure storefront -> add product -> publish -> buyer order -> fulfill -> settlement -> review/report.

## Buyer
Must-have inner pages:
- Marketplace browse
- Product detail
- Storefront
- Cart/checkout
- Order history/detail
- Delivery/tracking
- Refund/dispute
- Reviews/support

Flow:
- Browse -> select product -> cart/checkout -> payment -> order created -> seller fulfills -> delivery/completion -> review or dispute/refund.

## Field Agent
Must-have inner pages:
- Assigned growers/visits
- Verification detail
- Field checklist
- GPS/photos/evidence
- Visit report
- Route/list
- Academy training/certificates
- Performance report

Flow:
- Assignment -> field visit -> evidence submit -> verification recommendation -> coordinator/admin decision -> report updated.

## State Coordinator
Must-have inner pages:
- State dashboard
- LGA drilldown
- Growers/providers/agents in assigned state
- Verification queues
- Field agent workload
- Training participation
- Certificate oversight
- Resource allocation
- State reports

Flow:
- Assigned state -> view LGAs -> manage verification and agents -> review escalations -> communicate -> generate state report.

## National Coordinator
Must-have inner pages:
- National dashboard
- State comparison
- Program KPIs
- Certificates oversight
- Training analytics
- Marketplace intelligence
- Field network performance
- Finance summaries
- National reports

Flow:
- National view -> compare states -> identify gaps -> allocate resources/issue directives -> monitor reports.

## Academy Learner
This is a cross-role identity; any stakeholder can become a learner.

Must-have inner pages:
- Catalog
- Course/program detail
- Registration/checkout
- My Learning
- Lesson/material player
- Quiz/exam
- Cohort/live class/attendance
- Certificates/pathways
- Refund request where eligible
- Feedback/rating

Flow:
- Enroll/pay -> course unlocked -> learn -> assessment -> completion -> certificate -> verification/download.

## Admin / Super Admin
Must-have inner pages:
- Governance/RBAC
- User multi-role assignment
- Module setup
- Registry applications
- Verification review
- Certificate type builder
- Certificate issuance/revocation where allowed
- Academy management
- Marketplace/provider approvals
- Wallet/refund oversight
- Support queue
- Reports intelligence
- Imports/exports
- Settings/system health/audit logs

Flow:
- Configure module/role -> user receives correct access -> actions recorded -> reports/audit available.
