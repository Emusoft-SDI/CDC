# Inner Page Inventory and Must-Haves

## Breathable UI Rules
- Show summary first, detail on click.
- Use tabs, filters, drawers, and accordions to prevent overcrowding.
- Avoid forcing users to create profile/farm/product/training everywhere. Show optional action cards that can be opened or dismissed.
- Each module gets its own workspace when it has many inner pages.
- Every action must show a result: draft, submitted, pending, approved, rejected with reason, issued, paid, refunded, completed, revoked, expired, exported, resolved, or audited.

## Registry and Verification
Must include:
- Application list
- Application detail
- Document review
- Field verification assignment
- Field evidence review
- Approval/rejection/request-more-info
- Grower certificate issuance
- Paid/free certificate setup
- 3-year validity for grower participation/credential certificates
- Revocation for role/participation/credential certificates
- Public certificate verification
- Batch verification
- Certificate type builder
- Import/export logs

## Certificates
Certificate types:
- Grower participation certificate: valid 3 years, revocable.
- Verified grower certificate: valid 3 years, revocable.
- Academy course certificate: permanent after issue, no delete/revoke for normal completion certificates.
- Group/pathway certificate: issued when required courses are complete; academy-style certificates normally permanent.
- Provider/seller/field/state/national credentials: validity and revocation rules configurable.

Certificate actions:
- View online
- Download
- Verify by QR/reference
- Renew where applicable
- Revoke where allowed
- Audit changes
