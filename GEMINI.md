# Project Principles & Review Standards

All contributions must adhere to the following 6-step review process:

1. **Functionality Review**: Ensure all changes are invariant to existing features and satisfy core requirements.
2. **Security Review**: Proactively secure against threats, including but not limited to DDoS, SQL injection, XSS, and CSRF.
3. **Code Quality Review**: Adhere to idiomatic PHP patterns; avoid "code smells" and ensure maintainability.
4. **AI Scope Discipline**: Avoid over-engineering, code duplication, spaghetti code, or excessive commenting. Keep changes surgical.
5. **Self-Review**: Every change must be reviewed by the AI's own internal logic checks prior to submission.
6. **Peer/User Review**: Significant architectural changes or implementations require explicit user sign-off before final commitment.
